## Overview

NVIDIA is looking for an architect to help change how the AI inference industry works. The Inference Service Provider team supports strategic partners that rely on Solutions Architecture support to improve performance, value, and reliability across NVIDIA Cloud Partner infrastructure.

The role spans full-stack inference, including intelligent routing, rack-scale disaggregation, and kernel optimization. It involves creating reference architectures for large GPU clusters and communicating with executives, distinguished engineers, and datacenter developers about scaling businesses, systems, and infrastructure. NVIDIA is seeking fast-learning technical agility and comfort working with partners or customers.

- Work with partners building cutting-edge inference services, explain the value of NVIDIA’s stack, and bring product insights back to NVIDIA.

- Accelerate inference pipelines with TensorRT-LLM, vLLM, SGLang, and other backends for integration with disaggregated inference.
- Evangelize DevOps best practices, including Kubernetes cluster management, compute-fabric configuration, and observability.
